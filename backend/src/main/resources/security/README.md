# Common password blocklist

`common-passwords.txt` is the top 10,000 list from
[SecLists](https://github.com/danielmiessler/SecLists), file
`Passwords/Common-Credentials/10k-most-common.txt`.

SecLists is distributed under the MIT license. The list is used only to reject
trivially guessable passwords; it is not a substitute for the minimum length
rule.
